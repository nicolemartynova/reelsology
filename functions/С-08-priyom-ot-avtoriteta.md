# С-08 · Каждый пункт — «приём от [известное имя]»

**Суть.** Пункты списка привязаны к известным людям и брендам: Шахерезада, Хичкок, авторы «Южного парка», Netflix, MrBeast. Каждый открывается фразой «второй приём — от Хичкока».

**Зачем.** Чужой авторитет добавляет вес советам. Имя — мини-хук для каждого пункта: зритель ждёт, при чём тут Хичкок.

**Когда применять.** Советы, которые реально восходят к известным источникам.

**Когда не применять.** Если связь с именем притянута — это заметно и подрывает доверие.

## Как сделать

1. Каждый пункт: имя + год → правило одной фразой → пример → вывод для зрителя.
2. Порядок — по времени (IX век → 1966 → 2011 → 2017 → 2024), это само по себе даёт движение.
3. На экране — ярлык «год + имя» и фото (Г-07).

## Примеры из источников

- `2026-10-30-DfBEhQSIC2C`, 0:10 / 0:20 / 0:38 / 1:02 / 1:17 — пять приёмов от пяти имён, по хронологии.
