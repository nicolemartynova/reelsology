# Т-03 · Крупный заголовок раздела с проявлением по буквам

**Суть.** На границе частей ролика сверху появляется огромный заголовок в две строки (узкий жирный шрифт), буквы проявляются одна за другой. Так же оформлена концовка.

**Зачем.** Заголовок отделяет вступление от основной части, как обложка главы. Проявление по буквам притягивает взгляд.

**Когда применять.** Один раз после хука («СЕКРЕТЫ МОНТАЖА») и в концовке («БОЛЬШЕ ПОЛЬЗЫ»).

**Когда не применять.** Не чаще двух раз за ролик, иначе теряется вес.

## Как сделать

1. Заголовок занимает ~60–70% ширины кадра, две строки, верх кадра (примерно 15–42% высоты), ниже зоны интерфейса.
2. Буквы появляются по одной, ~2 кадра на букву: слово из 8 букв — около 0,5 с.
3. Держится ~3–4 с, рядом можно добавить рукописную пометку со стрелкой.
4. Голова ведущего не перекрывается: заголовок над ней.

**В Remotion.** Строка разбивается на буквы, у каждой `opacity` от `frame - i*2`; ширину подгонять через `measureText`.
