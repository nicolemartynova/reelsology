# Разбор: «5 приёмов удержания, которые старше рилсов» — сплит-экран с анимированной доской

## Что рилс говорит
1. Шахерезада — интересное в конец, лучшее в следующий рилс → С-05.
2. Хичкок — сначала «бомба» (результат), потом путь → С-06.
3. «Южный парк» — «но / поэтому» вместо «и потом» → С-07.
4. Netflix — без приветствий и долгого контекста → Х-09.
5. MrBeast — перезацеп в середине → У-04.

## Что рилс делает
- **Сценарий:** хук-парадокс цифр с уколом → обещание «5 приёмов, применить сегодня» → 5 пунктов «приём от [имя]» по хронологии → призыв с кодовым словом → Х-10, С-08, С-03.
- **Хук (0–5 с):** заголовок-хук сверху на чёрном, ведущий снизу; анимация доски включается только с обещанием.
- **Монтаж:** сплит-экран, ведущий одним планом (единственная склейка на 1:20) → М-03.
- **Графика:** синяя доска-«чертёж» с карточками, полароидами, предметами; перелёты камеры со смазом каждые 4–9 с; ярлыки «год + имя» → Г-06, Г-07.
- **Текст и субтитры:** накопительные, по левому краю, над головой ведущего → Т-05.
- **Звук:** −14,1 LUFS, голос у подкастового микрофона.
- **Вкус:** один фирменный синий на всю графику, бумажные карточки, тёмная бирюзовая комната ведущего.
