# Ниша: дизайн и визуал

Пока один рилс в базе: DZH-lOws3V0 (палитры «база + акцент», 4,7 млн просмотров). Этого мало для выводов, ниже только наблюдения.

- Доказательство — сам визуал: цвет, шрифт, макет в кадре. 3D-буквы с HEX-кодами показывают совет без слов (В-01).
- Формат одной формулы × 4 (С-27) удобен для подборок: палитры, шрифты, приёмы вёрстки.
