# С-21 · Формат-витрина «команда → результат» × N

**Суть.** Ролик без объяснений: запись экрана телефона, где набирается короткая команда (в чат-боте, приложении, сервисе), отправляется — и через 0,5 с на весь экран идёт готовый результат. Цикл повторяется 5–7 раз подряд, в конце — сетка всех результатов и кодовое слово.

**Зачем.** Хук — сам интерфейс: зритель видит, как печатается команда, и ждёт, что получится. Каждый цикл — маленькая петля «что сейчас будет → вот». Доказательство встроено: результат показан, а не обещан.

**Когда применять.** Показать инструмент, сервис или набор шаблонов: «вот что делает одна команда».

**Когда не применять.** Если результат скучный или медленный (больше 2–3 с ожидания). Если продукт сложный и без объяснения непонятен.

## Как сделать

1. Цикл 2,5–4 с: набор команды 0,5–1 с (видно клавиатуру, первые буквы и автоподсказку) → отправка → экран «обработка» 0,3–0,5 с → результат на весь экран 1,2–3 с.
2. Первый кадр — уже набор команды, без заставки.
3. Команды — короткие и говорящие сами за себя (название = что делает), под строкой подсказки — описание в 4–6 слов.
4. Результаты разные по виду: 3D, график, текст, интерфейс — чтобы каждый цикл выглядел новым.
5. Шаги ускоряются к середине: первые циклы показывают процесс целиком, дальше — только начало ввода и результат.
6. Финал 3–4 с: сетка-коллаж всех результатов (5×4) + заголовок + кодовое слово в плашке (С-03).
7. Без речи — музыка с битом; со речью — голос за кадром по одной фразе на цикл.

**В Remotion.** Массив `{cmd, desc, result}`; на каждый — `<Sequence>` с компонентом-экраном (запись телефона или нарисованный UI) и `<OffthreadVideo>` результата. Финальная сетка — `display:grid` из тех же клипов.
