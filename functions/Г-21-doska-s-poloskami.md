# Г-21 · Доска с пунктами, закрытыми цветными полосками

**Суть.** На маркерной доске заранее написан заголовок и нумерованный список, но каждый пункт заклеен цветной бумажной полоской. Ведущий срывает полоску в момент, когда переходит к пункту.

**Зачем.** Зритель видит, сколько пунктов впереди, и не знает, что под ними — открытая петля на весь ролик. Физическое действие (сорвать) — смена кадра без склейки.

**Когда применять.** Списки из 3–5 пунктов, офлайн-съёмка.

**Когда не применять.** Больше 5 пунктов — мелко. Если ролик снимается только на телефон без места для доски.

## Как сделать

1. Доска в кадре справа, ведущий слева, план по пояс; заголовок в рамке сверху.
2. Полоски разных ярких цветов на каждый пункт, на каждой — маленький квадрат-«замок».
3. Срыв — отдельным коротким планом 0,9–1,7 с, сразу после — крупный план надписи.
4. Перед первым срывом показать все закрытые пункты 1–2 с.
