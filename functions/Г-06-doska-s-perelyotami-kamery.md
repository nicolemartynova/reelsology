# Г-06 · Доска-«чертёж» с бумажными карточками и перелётами камеры

**Суть.** Графика — одна большая виртуальная доска: насыщенный синий фон с белой сеткой, на нём бумажные карточки с текстом, фото-полароиды, вырезанные предметы (будильник, рулетка, бомба, хлопушка, пульт). «Камера» перелетает по доске от одной группы к другой с сильным размытием в движении.

**Зачем.** Сплошное движение без склеек — глазу всё время есть за чем следить. Бумажные карточки выглядят «ручными» и живыми, а предметы иллюстрируют каждую мысль буквально.

**Когда применять.** Разговорный формат (М-03), объяснения, где нужно показать мысль картинкой.

**Когда не применять.** Без времени на анимацию: доска собирается дольше обычных плашек.

## Как сделать

1. Фон: один фирменный цвет (здесь насыщенный синий) + тонкая светлая сетка, лёгкая неровность бумаги.
2. Элементы: белые карточки с чёрным жирным текстом и лёгкой тенью, слегка повёрнуты (±2–5°); вырезанные предметы с тенью.
3. Каждая мысль — своя группа элементов на доске.
4. Переход между группами — «перелёт» камеры: ~8–12 кадров, смаз в направлении движения на пике (как М-02). Перелёт каждые ~4–9 с.
5. Внутри группы элементы появляются по одному, на ключевые слова.
6. Лёгкое постоянное покачивание или приближение доски, чтобы она не стояла мёртво.

**В Remotion.** Одна большая сцена (например, 3000×6000) с элементами в абсолютных координатах. «Камера» — `translate` и `scale` всей сцены по ключевым кадрам, `filter: blur` на перелётах.
