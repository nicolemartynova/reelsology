# Brand Kit — стиль пользователя

Заполняется на интервью (`setup`) из ответов пользователя и его референсов — каждое поле `<< … >>`. Здесь нет стиля по умолчанию: что не выбрано, то спрашивается. Значения, которые читает код, — в `video/reels.config.json`; этот файл — их человеческое описание и пожелания.

## 1. Кто и для кого
- Бренд / канал: `<< >>`
- В кадре: `<< кто ведёт, какая обстановка >>`
- О чём ролики: `<< >>`
- Площадки и хэндлы: `<< >>`
- Аудитория: `<< >>`
- Тон: `<< >>`
- Язык роликов: `<< >>`
- Финальный призыв: `<< >>`

## 2. Палитра
| роль | hex | откуда (ответ / референсы / логотип) |
|---|---|---|
| dark — плашки, скримы | `<< >>` | |
| light — текст | `<< >>` | |
| accent — выделение | `<< >>` | |
| pain — карточка «так не надо», если нужна | `<< >>` | |

Что выделяется акцентом: `<< цифры / ключевые слова / призывы >>`
Каких цветов не надо: `<< >>`

## 3. Шрифты
- Текст (субтитры, карточки): `<< >>` — характер: `<< >>`
- Постер: `<< >>`

## 4. Субтитры
- Где: `<< гуляют по кадру / нижняя рельса / центр >>`
- Размер: `<< >>` · жирность: `<< >>` · регистр: `<< >>`
- Выделение: `<< цветом / размером / и то и другое / без >>`
- Подложка: `<< нет / плашка под строкой >>`

## 5. Графика
- Карточки: `<< стекло / плотные / без >>`, как часто: `<< >>`
- Стикеры-пиктограммы в паузах: `<< да / нет >>`
- Постер-заголовок за головой в начале: `<< да / нет >>`, регистр `<< >>`, подзаголовок `<< да / нет >>`
- Б-ролл / вставки: `<< нет / до N на ролик >>`

## 6. Движение и картинка
- Темп анимаций: `<< спокойный / обычный / быстрый >>`
- Панч-ины (смена крупности на склейках): `<< нет / мягкие / сильные >>`
- Грейд и виньетка: `<< да / нет >>`

## 7. Звук
- Звуковые акценты: `<< нет / есть — какой характер >>`
- Громкость мастера: `<< как в ленте (−14 LUFS) / тише >>`

## 8. Чего не делать (со слов пользователя)
- `<< >>`

## Технические ограничения (не вкус)
- **Нижние 15% кадра** и **верхние 8%** — под интерфейсом платформы: ключевой текст туда не ставится.
- **Боковые 10%** — title-safe; Instagram на высоких экранах срезает ~9% с каждого бока.
- Тонкие цветные линии (<4px) расползаются на компрессии соцсетей.
- Шрифты обязаны поддерживать алфавит языка роликов.
