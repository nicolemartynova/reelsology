# Проект монтажа рилсов

Создан навыком Рилсология. Настройка: откройте Claude Code в этой папке и напишите что угодно, агент начнёт интервью. Или наберите `/setup`.

Новый ролик: положите дубль в `takes/` и напишите «смонтируй takes/1.MOV». Инструкции для агента лежат в `CLAUDE.md`.
