# У-05 · Пустой нумерованный список, который заполняется на глазах

**Суть.** С первого кадра на экране — заголовок и пустые номера 1…17. Под голос пункты появляются по одному, справа меняется пример к текущему пункту.

**Зачем.** Пустые номера — видимое обещание: зритель сразу видит, сколько осталось, и хочет увидеть список целиком. Готовый список сохраняют, чтобы вернуться.

**Когда применять.** Подборки из 7+ пунктов: форматы, ошибки, вопросы, районы, документы.

**Когда не применять.** Если пунктов 3–5 — проще счётчик (У-01).

## Как сделать

1. Светлый лист, заголовок сверху (Т-06), под ним колонка номеров 1…N мелким текстом, слева, ~40% ширины.
2. Пункт появляется в момент, когда его называют; темп ~0,9 с на пункт (17 пунктов за 15,5 с).
3. Справа — вертикальное окно ~40% ширины с примером к текущему пункту, меняется вместе с пунктом; под ним подпись-ярлык.
4. Последний кадр — полный список, держать 0,5–1 с (кадр для паузы и скриншота).
