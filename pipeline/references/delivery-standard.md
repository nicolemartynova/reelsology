# Стандарт сдачи

Всё ниже не видно в QuickTime, но ломает ролик на площадках. `scripts/check.py` проверяет каждый пункт.

## Файл

| Параметр | Надо | Что будет иначе |
|---|---|---|
| Кодек | H.264 High | |
| Пиксели | `yuv420p` | `yuvj420p` (полный диапазон) площадки читают неверно |
| Цвет | BT.709, ТВ-диапазон (`tv`), метки primaries / transfer / matrix = `bt709` | Remotion по умолчанию пишет BT.601 полного диапазона без меток → сдвиг контраста, чёрного, белого и кожи |
| Частота кадров | 30 fps, постоянная | |
| Ключевой кадр | каждую секунду (`-g 30`) | больше артефактов после пережатия площадкой |
| Звук | AAC, 48 кГц, стерео, 192k | `loudnorm` внутри поднимает до 192 кГц, AAC получается 96 кГц → тишина на части телефонов и в конвертере Instagram. После `loudnorm` всегда `-ar 48000` |
| Контейнер | `-movflags +faststart` (moov в начале) | площадка начинает обработку до конца загрузки и принимает файл за битый |
| Громкость | двухпроходный `loudnorm` к −14 LUFS, пик −1.5 dBTP | однопроходный недотягивает примерно на 1.5 LU |

## Качество картинки

- Нарезка в разрешении исходника (4K остаётся 4K), без увеличения меньших исходников.
- Нарезка crf 14, мастер crf 12, кадры Remotion в PNG (JPEG 80 даёт ореолы вокруг субтитров и полосы на небе).
- Одно финальное сжатие под площадку — в `deliver.sh`.

## Файлы площадок (`deliver.sh`)

- `final-ig.mp4` — Instagram и TikTok, 1080×1920, level 4.1, до 20 Мбит/с.
- `final-shorts.mp4` — YouTube Shorts, 1440×2560, level 5.1, до 35 Мбит/с. 2K выбрано намеренно: на таком разрешении YouTube отдаёт VP9/AV1 вместо H.264, это заметно чище.
- Старые мастера (BT.601 полного диапазона, 96 кГц) `deliver.sh` переводит правильно, новые проходят без сдвига цвета.

## Safe-зоны (1080×1920)

- Верх 0–154 px и низ от 1632 px — без ключевого текста.
- Правая колонка кнопок Reels: x ≥ 960, y 1080–1700.
- По бокам ≥ 108 px: Instagram на высоких экранах срезает около 9% сбоку.
- Лента 4:5 показывает кроп y 285–1635 — обложка должна работать и так.

## Проверка вручную

```bash
python3 scripts/check.py FILE              # мастер
python3 scripts/check.py --platform FILE   # файл площадки: ещё и ключевые кадры
```

Быстрый вариант без скрипта:
```bash
ffprobe -v error -show_entries stream=pix_fmt,color_range,color_space,sample_rate -of default=nw=1 FILE
```
Должно быть: `yuv420p`, `tv`, `bt709`, `48000`.

## Советы при загрузке

- Instagram: включить «Загружать в наивысшем качестве». TikTok: «Загрузка в высоком качестве».
- Shorts — через YouTube Studio с компьютера.
- Не пересылать ролик через мессенджеры (пережимают): AirDrop или файлом.
- Не заливать ролик, скачанный с другой площадки.
