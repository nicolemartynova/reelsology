# С-02 · Структура «хук-сравнение → заголовок → 5 шагов → призыв остаться»

**Суть.** Ролик ~54 с собран по жёсткой схеме: хук-сравнение (5,7 с) → обещание и заголовок раздела (4 с) → пять шагов по 6–9 с каждый → короткий призыв остаться (3,5 с).

**Зачем.** Зритель с первых секунд понимает, что получит и сколько это займёт; каждый шаг — короткий и законченный.

**Когда применять.** Обучающие ролики, советы, разборы.

**Когда не применять.** Истории и кейсы — им нужна другая драматургия.

## Как сделать

1. 0–6 с: хук-сравнение (Х-01) с вопросом «какой залетит».
2. 6–10 с: обещание («рассказываю секреты, которые повторите уже в следующем ролике») + заголовок (Т-03), «часть 1» (У-02).
3. 10–50 с: пять шагов, у каждого: номер голосом («Первое»), счётчик (У-01), 1 мысль + 1 наглядный пример (Г-03, Г-04). Длина шага 6–9 с.
4. Последние 3–4 с: «Оставайся, если хочешь больше…» + заголовок с ником.
5. Темп речи ~2,8 слова в секунду, без пауз (М-01).
