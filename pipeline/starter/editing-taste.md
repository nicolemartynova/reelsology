# Editing Taste — монтажный вкус пользователя

Заполняется на интервью из ответов пользователя и его референсов (`exemplars.md` → «Профиль вкуса»). Своего вкуса у проекта нет: что здесь не заполнено, агент спрашивает, а не придумывает.

## 1. Темп
- Длина плана / частота смены картинки: `<< из референсов: медиана … с >>`
- Скорость речи после нарезки: `<< как есть / быстрее (cut.speed) >>`
- Паузы: `<< режем плотно / оставляем воздух >>`

## 2. Хук (первые 1–3 секунды)
- Что в хуке: `<< постер с текстом / вопрос / действие / сразу речь >>`

## 3. Графика
- Сколько графики: `<< почти на каждой фразе / на ключевых мыслях / минимум >>`
- Что идёт карточкой: `<< цифры / шаги / списки / … >>`
- Голое лицо без графики — максимум: `<< … с >>`

## 4. Крупность
- Панч-ины: `<< где: повороты мысли / цифры / не нужны >>`

## 5. Концовка
- Чем заканчивается: `<< призыв / стикер / просто последняя фраза >>`

## Техническая гигиена (не вкус — так делается всегда)
Это дефекты, которые слышит и видит любой зритель, — к стилю отношения не имеют:
1. **Без дублей и повторов фраз** — оставляем последний чистый дубль (повторы ищутся по кускам: `chunks.py`).
2. **Без фальш-стартов** («зайд… зайди в бота»).
3. **Без обрезанных хвостов слов** — конец по реальному затуханию звука + ~0.08 с (это делает `cut.py`).
4. **Без склеек посреди гласной** и без рассинхрона звука и картинки.
5. **Панч-ин — только на склейке** (см. CLAUDE.md, «Механика»).
