# Т-07 · Субтитры рядом с объектом фокуса, ключевое слово жёлтым

**Суть.** Субтитры не стоят в одном месте, а ставятся рядом с тем, на что смотрит зритель в этом плане (у лица, у руки, у предмета). 1–3 слова, белый узкий жирный капс, одно ключевое слово — жёлтым и крупнее. Слова собираются в небольшой «блок» с разными размерами.

**Зачем.** Текст и объект читаются одним взглядом — субтитр не уводит внимание из точки фокуса (работает вместе с М-04). Жёлтое слово — главное в фразе.

**Когда применять.** Монтаж из разных планов, где точка внимания меняется.

**Когда не применять.** Говорящая голова одним планом — там проще фиксированное место (Т-01).

## Как сделать

1. Для каждого плана — точка фокуса; субтитр рядом с ней, не перекрывая лицо.
2. Белый узкий жирный капс, ~2,5–3% высоты кадра; ключевое слово — жёлтый (~#F5E33B), в 1,2–1,5 раза крупнее.
3. 1–3 слова; при длинной фразе слова выстраиваются лесенкой с разными размерами.
4. Финальное слово ролика («ОБНЯЛ») — крупно, жёлтым.

## Примеры из источников

- `2026-10-30-DdREsBwvXEt`, 0:05–0:06 «сейчас твой ВЗГЛЯД» у лица; 0:12–0:16 «КАЖДЫЙ новый кадр…» у книги; 0:23 «ОБНЯЛ» крупно жёлтым.
- `2026-10-30-DeoxT77I9wY`, весь ролик — 1–3 слова белым узким капсом прямо над верхним краем ноутбука, между лицом и графикой, без акцентного цвета.
