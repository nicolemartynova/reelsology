# М-05 · Хук-фраза, разрезанная на 3 плана разной крупности

**Суть.** Первая фраза разбита на 3 куска по ~1,1 с, и каждый кусок — свой план: средний, общий, крупный. Склейки на границах смысловых кусков фразы.

**Зачем.** Три смены картинки за 3 секунды при одной непрерывной фразе: хук звучит цельно, а глазу всё время новое.

**Когда применять.** Если есть 2–3 камеры или дубли с разных точек одной и той же фразы.

**Когда не применять.** С одной камеры — тогда панч-ин на склейке (зум кропом) или новый слой графики (Х-02).

## Как сделать

1. Снять хук одновременно с 2–3 точек или 3 раза одинаково с разных точек.
2. Разбить фразу на куски по смыслу: «Как незаметно / склеивать кадры / как в кино».
3. Порядок крупностей: средний → общий → крупный (кульминация на крупном).
4. Длина кусков ~1,0–1,2 с (30–36 кадров).
5. Субтитр — текущий кусок фразы.
