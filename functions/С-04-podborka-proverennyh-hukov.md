# С-04 · Формат-подборка «N проверенных примеров с доказательствами»

**Суть.** Ролик целиком — подборка из 5 примеров без вступления. Каждый пример ведущий исполняет сам, потом показывает оригинал с цифрой. В конце — призыв за подробностями.

**Зачем.** Первый пример и есть хук ролика. Нет вступления, которое можно пролистать. Подборки сохраняют «на потом» — это сильный сигнал алгоритму.

**Когда применять.** Хуки, фразы для переговоров, ошибки покупателей — всё, что можно показать коротким примером.

**Когда не применять.** Если примеры не проверены цифрами — тогда это просто список мнений.

## Как сделать

1. Сразу первый пример, без «привет» и «сегодня расскажу» (с 0,1 с).
2. 5 примеров по ~6–7 с: ведущий 3–5 с + доказательство 2–3 с (У-03, Г-05).
3. Самый сильный пример — первым.
4. Концовка 3–4 с: призыв (С-03).
5. Длина ~35 с, ~100 слов (2,8 слова в секунду).
