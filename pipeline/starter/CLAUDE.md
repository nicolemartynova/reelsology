# Монтаж рилсов в Claude Code

Проект создан навыком Рилсология. Приёмы, сценарии и разборы рилсов берутся из навыка, монтаж и сдача идут здесь.

Пайплайн монтажа вертикальных роликов «говорящая голова» на Remotion: сырой дубль → нарезка пауз → расшифровка → графика и субтитры → звук → мастер → обложка → (черновик публикации).

## Первым делом в каждой сессии

1. Открой `video/reels.config.json`. Если `"configured": false` — проект ещё не настроен: **до любой другой работы** проведи интервью по скиллу `setup` (`.claude/skills/setup/SKILL.md`; если скилл не загружен — прочитай файл и выполни его как инструкцию).
2. Если настроен — задачи: «смонтируй ролик / новый дубль» → скилл `new-video`; «опубликуй / сделай черновик» → `publish`; «проверь доступ» → `bash video/scripts/doctor.sh`; «подключи <сервис>» → `SERVICES.md` и блок 4 скилла `setup`; «разбери референсы», «поменяй палитру / шрифты / стиль» → соответствующий блок `setup`.

## Стиль — только пользователя

У проекта **нет своего стиля**. Палитра, шрифты, субтитры, карточки, стикеры, постер, темп, панч-ины, грейд, звук — всё выбирает пользователь на интервью или берётся из его референсов, и живёт в:
- `video/reels.config.json` — значения, которые читает код (`colors`, `fonts`, `style`, `cut`, `audio`);
- `brand-kit.md` и `editing-taste.md` — то же словами, плюс его пожелания;
- `exemplars.md` → «Профиль вкуса» — что общего в его референсах.

Если чего-то в профиле нет — **спроси пользователя**, не подставляй свой вкус, «типичный стиль рилсов» или что-то из примеров. Ничего не угадывай о человеке по почте аккаунта, имени в системе, названию папки или ссылке на репозиторий.

Код читает стиль через `video/src/brand.ts` (`BRAND`, `FONT`, `STYLE`, `PACE`, `SAFE`) — никогда не хардкодь hex и названия шрифтов в компонентах.

## Команды

```bash
cd video
npm run dev                  # Remotion Studio (превью), или preview_start "studio"
npm run lint                 # eslint + tsc — должно быть чисто перед рендером
bash scripts/doctor.sh       # что установлено, чего не хватает, работают ли ключи и MCP
python3 scripts/refs.py URL…                      # скачать и измерить рилсы-референсы → takes/refs/ (+ palette.png)
python3 scripts/variants.py out/x.png 70,368 '{"label":"A","colors":{…}}' …   # варианты стиля кадрами
python3 scripts/chunks.py ../takes/1.MOV          # дубли и фальш-старты до нарезки
python3 scripts/cut.py ../takes/1.MOV             # дубль → public/footage.mp4 + captions.json (темп — cut в профиле)
python3 scripts/matte.py <TITLE_OUT>              # вырезка человека для постера (один процесс, ~11 ГБ памяти)
npx remotion still MyComp /tmp/t.png --frame=N --timeout=120000
bash scripts/draft.sh        # быстрый черновик 540p, не для сдачи
npm run master               # чанковый рендер + звук + loudnorm + проверка → out/final-master.mp4
bash scripts/deliver.sh out/final-master.mp4     # файлы площадок → final-ig.mp4, final-shorts.mp4 + проверка
python3 scripts/check.py FILE                    # проверка файла по стандарту сдачи
bash scripts/archive.sh ../edits/N               # всё для перерендера → edits/N/project-state
```

## Устройство

- `video/reels.config.json` — профиль пользователя. До интервью — нейтральные заглушки (серые цвета, системный шрифт, минимум графики).
- `video/src/Root.tsx` — композиции; принудительно грузит выбранные шрифты (с кириллическим образцом) внутри `delayRender` и падает с понятной ошибкой, если шрифт не подключён.
- `video/src/Composition.tsx` — `MyComp` 1080x1920 30fps: `DURATION`, `TITLE` (постер), `BEATS` (карточки), `FLOATS` (стикеры). Проверяет, что окна стикеров не пересекаются с карточками.
- `video/src/scenes/Title.tsx` — постер ЗА спикером. `scenes/Captions.tsx` — субтитры.
- `video/src/ui/Footage.tsx` — таблица панч-инов + вырезка человека поверх постера. Без `public/footage.mp4` рисует заглушку.
- `video/src/ui/Card.tsx` — карточка + `Float` (стикер), `Photo`, `Clip`, `Tag`, библиотека пиктограмм. `ui/Panel.tsx` — плашка, `Reveal`, `TYPE`, `EASE`. `ui/Sfx.tsx` — `Cue`, `Ticks`.
- `video/scripts/` — `cut.py`, `chunks.py`, `assemble.py`, `refs.py`, `variants.py`, `matte.py`, `draft.sh`, `master.sh`, `deliver.sh`, `check.py`, `archive.sh`, `cover-sticker.py`, `doctor.sh`.
- `video/public/sfx/` — звуки пользователя по ролям (`card`, `count`, `end`), если он их выбрал. В проекте их нет.
- `edits/N/` — архив готовых монтажей (в корне, не в `video/` — tsc компилирует всё, что там найдёт).
- `SERVICES.md` — подключение ElevenLabs / Higgsfield / 21st.dev / Buffer.
- `.claude/agents/` — субагенты: `script-beats` → `scene-builder` → `audio-agent` → `assembler`.

## Сдача

Ролик не сдаётся, пока `scripts/check.py` не сказал «meets the delivery standard». Нарезка идёт в разрешении исходника, ничего не уменьшается и не растягивается по дороге. Подробно: `delivery-specs.md`.

## Механика (как устроено и почему — это не вкус)

- **Постер за головой** (`style.poster.enabled`): `Title` рендерится в слот `behind` у `Footage`, ПОД покадровой вырезкой человека (`public/cut/NNNN.png`, rembg birefnet-portrait). Уходить он должен ровно на склейке (`TITLE_OUT`), иначе выход виден. Строки подгоняются по ширине через `measureText` с потолком `cap` — никогда не подбирай кегль руками; последняя строка должна читаться над волосами.
- **Панч-ин только на склейке.** Каждая граница бита в таблице `Footage.tsx` — реальная склейка из вывода `cut.py`. Смена крупности ровно на склейке превращает джамп-кат в панч-ин; посреди непрерывного плана она читается как зум, склейка без смены крупности — как глюк. Перерезал дубль → пересчитай таблицу. Силу задаёт `style.motion.punch` (`none` / `soft` / `strong`), таблица пишется в полную силу. Не уменьшай кадр ниже 1.0.
- **Карточки — строки таблицы `BEATS`**, один компонент `Card`, один кегль заголовка на ролик (`useHeadScale` меряет самую широкую строку). Карточка входит через 4 кадра после первого слова своей фразы — кадр бери из `captions.json` (секунды × 30). `count` — бегущий счётчик, всегда в паре с `<Ticks>`. Вид плашки — `style.cards` (`glass` / `solid` / `none`).
- **Стикеры (`FLOATS`)** — только если `style.stickers`; окно стикера не пересекается с окном карточки (Composition бросит ошибку).
- **Субтитры** (`scenes/Captions.tsx`): вид — из `style.captions`; механика фиксирована: ОДИН кегль на весь ролик (минимум по всем группам после `measureText`-подгонки), маска на строку (не на слово — иначе слова двух кеглей теряют общую базовую линию), никогда `filter: drop-shadow` на строке (растеризует и размывает), короткое служебное слово не заканчивает строку. `em: 2` и `"accent": 1` в `captions.json` назначаются по смыслу.
- **Анимации детерминированы:** только от `useCurrentFrame()`, никаких `useState`, `setTimeout`, CSS transitions, `Math.random()`. Темп — `PACE` из `style.motion.pace`.
- **До последнего кадра:** последняя фраза субтитров уходит к `until={DURATION - 14}` — проверяй ПОСЛЕДНИЙ кадр отдельно.

## Звук (механика)

- Звуки только пользователя (`style.sfx`), по ролям в `video/public/sfx/`. `Cue` молчит, если звук выключен или файла нет.
- **Бегущее число — `<Ticks>`**, тики разнесены в пространстве ЗНАЧЕНИЙ (обратный изинг): густо в начале, реже к концу — иначе тики и цифры читаются как два несвязанных события.
- Ставь `<Cue>` за 1–2 кадра ДО визуального пика, иначе звук опаздывает.
- Новый звук (генерация или файл пользователя): пик-нормализация до −1 dBFS; если звучит резко — смягчи тембр (lowpass, срез высоких, короткие фейды), а не только громкость. Характер звука — по профилю пользователя.
- `npm run master` → `out/final-master.mp4` + `out/preview.mp4` (540p). Громкость — `audio.lufs` из профиля. На площадки идут файлы из `scripts/deliver.sh`, не мастер.

## Сборка — грабли

- **Рендер чанками по 800 кадров** (`master.sh`). Один проход по длинной композиции падает где-то после ~2400 кадра — флейково, свежий браузер на чанк лечит. Любой краш ПРОЯВЛЯЕТСЯ как `delayRender("brand fonts") timed out` — шрифты не виноваты, ищи настоящую ошибку выше в логе.
- **Звук — отдельный `--codec=wav` проход**, чанки рендерятся `--muted`. Склейка поканального AAC даёт дыру ~20мс на каждом стыке.
- **Никогда `-shortest` на финальном муксе** — AAC короче на миллисекунды и обрезает видео. `master.sh` сверяет кадры с `DURATION`.
- **`--timeout=120000` на каждом рендере.**
- **Двухпроходный loudnorm.** Однопроходный недобирает ~1.5 LU.
- **Шрифты:** импортируй файлы ВЕСОВ (`@fontsource/x/600.css`), не сабсеты (`latin-600.css`) — у сабсетов нет `unicode-range`, кириллица молча уходит в системный шрифт. `measureText` хочет голое имя семейства (`FONT.text`), не CSS-стек.
- **rspack выключен специально** — Tailwind-лоадер под rspack молча ничего не делает.
- Remotion ставит `objectFit` инлайном на `OffthreadVideo` — передавай `style={{objectFit:"cover"}}`, класс проигрывает.
- **`out/final-master.mp4` переживает прошлый монтаж** — жди процесс `master.sh`, а не появление файла. Долгие задачи (матинг, мастер) — в фоне, ждать через `ps -axo command`, не через `pgrep`.
- Сырые `.MOV` с айфона — вертикаль, записанная как 1920x1080 + `rotation=-90`; ориентацию смотри `ffprobe -show_entries stream_side_data=rotation`.
- **Не стабилизируй дубль, снятый со штатива** — vidstab добавит дрожь. Съёмка с рук — стабилизируй ИСХОДНИК до `cut.py`, никогда готовую нарезку.

## Безопасность и деньги

- Ключи — только в `video/.env` (в git не попадает) и, для 21st.dev, в локальной (`--scope local`) настройке MCP. Никогда не печатай ключ, не вставляй его в коммитящиеся файлы (`.mcp.json` — только адреса), не проси прислать ключ в чат. Прислал — не используй, посоветуй отозвать и создать новый.
- Референсы (`takes/refs/`) — только для разбора: не публикуй их и не вставляй в ролики. Куки браузера для yt-dlp (`COOKIES_FROM`) — только с явного согласия.
- Генерации ElevenLabs / Higgsfield тратят кредиты: ровно то, что нужно, цена заранее, перед пачкой — спросить.
- Публикация (Buffer) — только черновик; опубликовать или поставить в расписание — только после явного «да» на конкретный пост.
