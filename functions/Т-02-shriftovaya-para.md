# Т-02 · Шрифтовая пара — узкий жирный и рукописный, без обводки и теней

**Суть.** Только свои загруженные шрифты, не стандартные из приложения. Заголовки — высокий узкий жирный гротеск капслоком. Рядом — рукописный шрифт для коротких пометок («чтобы делать так», «шрифты уже в описании», «в блоге @…»). Никакой обводки и теней.

**Зачем.** Стандартные шрифты приложения сразу выдают новичка. Контраст «строгий узкий + живой рукописный» выглядит как дизайн, а не как шаблон.

**Когда применять.** Всё оформление ролика: заголовки, пометки, карточки.

**Когда не применять.** Не больше двух шрифтов на ролик (плюс нейтральный для субтитров).

## Как сделать

1. Заголовок: узкий гротеск (condensed), жирный, капс, плотный межстрочный.
2. Пометка: рукописный шрифт, мелкий, под углом ~−10…−15°, часто со стрелкой к объекту.
3. Обводка 0, тень 0.
4. Шрифты загрузить в проект; в нашем конвейере — только из профиля пользователя (brand.ts).
