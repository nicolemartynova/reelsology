# Г-19 · Переключатели-«тумблеры», которые включаются по одному

**Суть.** Белая панель в стиле настроек iPhone из 3 строк, у каждой — тумблер. Ведущий называет пункт — его тумблер щёлкает в зелёный.

**Зачем.** Знакомый каждому жест «включить» = «готово». Шаги процесса превращаются в чек-лист, который заполняется на глазах.

**Когда применять.** Короткие процессы из 3 шагов: «Отправил запрос → Получил подборку → Забронировал просмотр».

**Когда не применять.** Больше 4 пунктов — панель мелкая и не читается.

## Как сделать

1. Панель 60% ширины, на уровне груди, белая, скругление 4%, строки по 5% высоты кадра, текст тёмный 2,8% высоты.
2. Тумблеры серые; включение — бегунок влево→вправо и заливка зелёным #34C759 за 6 кадров, лёгкий щелчок (З-01).
3. Интервал между тумблерами — по словам речи или 0,4–0,6 с.

**В Remotion.** Строки из массива, `on = frame >= start[i]`; бегунок `translateX(interpolate(frame-start[i],[0,6],[0,20]))`.
