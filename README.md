# Рилсология

Навык Claude Code на весь путь рилса. У него две части, они дополняют друг друга.

**Приёмы.** Обучаемая база. Присылаешь ссылку на рилс, Claude его скачивает, расшифровывает, раскладывает на кадры и склейки и сохраняет каждый приём как пронумерованную функцию. Потом применяет эти приёмы к твоим роликам и сценариям.

**Техника.** Конвейер для роликов «говорящая голова» на Remotion: от 4K-дубля до файлов под Instagram, TikTok и YouTube Shorts, которые не портятся на площадках. Файл не сдаётся, пока не пройдёт проверку по стандарту.

- [SKILL.md](SKILL.md) — как навык работает (обучение, каталог, применение, совет).
- [CATALOG.md](CATALOG.md) — список всех функций по категориям.
- [functions/](functions) — карточки функций.
- [sources/](sources) — разборы присланных рилсов.
- [principles.md](principles.md) — общие правила, подтверждённые несколькими рилсами.
- [stats.md](stats.md) — просмотры и лайки всех разобранных рилсов.
- [checklist.md](checklist.md) — универсальный чек-лист рилса для любой ниши.
- [sounds.md](sounds.md) — словарь звуков: какой звук, куда ставить, где взять.
- [resources.md](resources.md) — сервисы для мемов, фраз из фильмов и стоков.
- [pipeline/](pipeline) — техника: чистый стартовый проект, скрипты, [стандарт файла](pipeline/references/delivery-standard.md), [журнал ошибок](pipeline/references/incidents.md).
- [niches/](niches) — советы по нишам: чем доказывать, какие форматы, ограничения.

Почти все чужие рилсы в базе — из ниши «обучение контенту» (46 рилсов; ещё 1 про дизайн и 4 про недвижимость). Поэтому каждый принцип помечен как универсальный или зависящий от ниши, а нишевые советы вынесены отдельно.

По желанию можно подключить Apify. `scripts/apify.py stats` подтягивает просмотры, которые Instagram без входа не отдаёт. `scripts/apify.py own <ник>` загружает свои рилсы, чтобы разобрать их рядом с базой и проверить приёмы на своей аудитории. Нужен токен в `APIFY_TOKEN` или в файле `~/.config/reelsology/apify_token`.

Категории: Х хуки · У удержание · М монтаж · Т текст и субтитры · Г графика · З звук · С сценарий · В вкус.

Скачанные видео и кадры лежат в `work/` и в репозиторий не попадают.

## Установка

```bash
git clone https://github.com/nicolemartynova/reelsology ~/.claude/skills/reelsology
```

Для разборов и сценариев этого достаточно. Для монтажа напишите в Claude Code «настрой рилсологию»: агент создаст проект, проверит, что установлено, предложит поставить недостающее и расспросит о стиле. Варианты он покажет готовыми кадрами.

Нужно: python3 + Pillow, Node 18+, ffmpeg 7+, yt-dlp, whisper.cpp с моделью `ggml-large-v3-turbo` (или ключ ElevenLabs), для вырезки человека `rembg[cpu]`.

Для сценариев: навык `humanizer-ru` в `~/.claude/skills/humanizer-ru/` — им вычитывается каждый написанный сценарий перед ответом.
