# С-07 · «Но / поэтому» вместо «и потом» между событиями

**Суть.** События связываются словами «но» и «поэтому», а не «потом». Правило авторов «Южного парка»: каждое следующее событие — либо препятствие, либо следствие.

**Зачем.** «Потом, потом, потом» — список, скучно. «Но» добавляет конфликт, «поэтому» — движение. История начинает затягивать.

**Когда применять.** Любой рассказ из нескольких шагов: кейс, история сделки, путь клиента.

**Когда не применять.** Инструкции по шагам, где важна простая последовательность (там нужен счётчик, У-01).

## Как сделать

1. Выписать события по порядку.
2. Между каждыми двумя поставить «но» (что помешало) или «поэтому» (что из этого вышло). Если ни то ни другое не подходит — событие лишнее.
3. На экране связки можно показывать карточками: «НО» красным, «ПОЭТОМУ» синим.
