# Т-04 · Субтитры фразой на жёлтой плашке

**Суть.** Вся фраза целиком (2–3 строки) на ярко-жёлтой скруглённой плашке, чёрный жирный текст. Висит, пока звучит фраза.

**Зачем.** Читается на любом пёстром фоне (магазин, улица). Фразу можно прочитать целиком без звука.

**Когда применять.** Съёмка в движении и на пёстром фоне, где нет ровного места под текст. Хорошо для хуков: хук виден целиком с первого кадра.

**Когда не применять.** Если важен «дорогой» чистый вид. Это **противоположный подход к Т-01**: автор первого рилса называет такие подложки «дешёвыми». Выбор — по стилю пользователя.

## Как сделать

1. Плашка жёлтая (~#FFE500), скругление ~12 px, отступы ~16×10 px.
2. Текст чёрный, жирный, ~2,6% высоты кадра (~50 px на 1080×1920), по центру, 2–3 строки.
3. Высота плашки — ~62–70% кадра, на груди.
4. Одна фраза — одна плашка; меняется вместе с фразой.

## Примеры из источников

- `2026-10-30-DeT3lrzoBCf`, весь ролик — каждый хук целиком на жёлтой плашке.
- `2026-10-30-Dc_mDZrMZJz`, каждая фраза-хук целиком на жёлтой плашке чёрным жирным, по центру нижней половины.
