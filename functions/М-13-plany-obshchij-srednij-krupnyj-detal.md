# М-13 · Связка планов «общий → средний → крупный → деталь»

**Суть.** Одно действие снимается четырьмя крупностями и монтируется по нарастанию: общий (где мы, всё пространство) → средний (само действие) → крупный (лицо, руки, предмет) → деталь (фактура, мелочь). Каждый план 0,3–1,1 с. К общему возвращаются, когда в пространстве что-то изменилось.

**Зачем.** Даже бытовое действие выглядит как кино; глаз всё время получает новую информацию и не скучает.

**Когда применять.** B-roll места или предмета: общий — гостиная, средний — человек открывает штору, крупный — рука на ручке балкона, деталь — вид за окном.

**Когда не применять.** Под плотную речь с важными словами — быстрая смена отвлекает.

## Как сделать

1. Снять каждое действие 4 крупностями (общий, средний, крупный, деталь).
2. Монтаж: 0,6 / 0,6–1,0 / 0,3–1,0 / 0,5–1,0 с; склейки по движению.
3. Цикл повторить 2–3 раза с разными действиями, между циклами — общий план.
4. Обучающий вариант: подписать каждый план словом («общий», «деталь») по центру, голос произносит подпись.
