# Разбор: «Какая должна быть идеальная длина твоего Reels» — 4 формата и их хронометраж

## Что рилс говорит
У каждого формата своя длина: экспертный 45–55 с, личная история 60–70 с, говорящая голова 30–40 с, рилс без слов 7–14 с. Короче — не раскрываешь тему, длиннее — зритель устаёт.

## Что рилс делает
- **Хук (0–2,7 с):** ведущий у Бурдж-Халифы ночью, на фасаде его лицо, рядом шкала высоты, заголовок по буквам → Х-26.
- **Структура:** 4 пункта по 5–7 с, каждый снят в своём формате → С-26.
- **Графика:** на каждом пункте блок «ярлык + диапазон + шкала с ползунком», подпись меняется по ползунку → Г-24.
- **Текст:** в хуке — субтитры по одному слову; в пунктах их заменяет графика.
- **Концовка:** «СОХРАНЯЙ» крупно → С-09.
- **Звук:** речь не распознана (громкость не измерилась: дорожки, похоже, нет или она пустая). Выводы только по кадрам.
