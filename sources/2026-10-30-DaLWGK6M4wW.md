# Разбор: «секреты чистого монтажа» — 5 шагов, как сделать рилс похожим на блогерский

## Что рилс говорит
1. 0:10–0:17 — место под субтитры продумывать ещё при съёмке, без «дешёвых» подложек → Т-01.
2. 0:17–0:26 — свои читабельные шрифты вместо стандартных, без обводки и теней → Т-02.
3. 0:26–0:34 — резать так, чтобы между фразами не было пауз; показано сравнение «с паузой / без» → М-01.
4. 0:34–0:43 — базовые анимации входа и выхода всех наложений, к ним звуки ~10% → Г-01, З-01.
5. 0:43–0:50 — riser в начале ~15%, музыка под основной частью 2–3% → З-02, З-03.

## Что рилс делает
- **Хук (0–5,7 с):** сравнение двух роликов с цифрами просмотров, речь с первого кадра, новый слой графики каждую ~1 с без склеек → Х-01, Х-02.
- **Структура:** хук → «часть 1. СЕКРЕТЫ МОНТАЖА» → 5 шагов по 6–9 с → «Оставайся…» + «БОЛЬШЕ ПОЛЬЗЫ в блоге» → С-02, У-02, Т-03.
- **Монтаж:** 9 планов, медиана 5,7 с, склейки только на смене шага; переход смазом после заголовка → М-02.
- **Текст и субтитры:** одно слово на чёрной футболке; узкий капс-заголовок + рукописные пометки → Т-01, Т-02, Т-03.
- **Графика:** всё над головой: окна, карточки «плохо / надо!», скриншоты CapCut, объёмные 3D-буквы; счётчик «Шаг N/5» → Г-02, Г-03, Г-04, В-01, У-01.
- **Звук:** −14,6 LUFS, плотная речь; glitch/whoosh на графике.
- **Подача:** указка в руках, жесты в сторону будущей графики → С-01.
- **Вкус:** тёмный тёплый интерьер, ведущая по центру в чёрном → В-02.
