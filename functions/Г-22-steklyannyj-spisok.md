# Г-22 · Стеклянный список над головой: раскрывается, потом сворачивается до пункта

**Суть.** Над головой — стопка полупрозрачных «стеклянных» строк. Сначала они размыты, затем проявляются названия пунктов с номерами. На разборе одного пункта список сворачивается до него, над ним красная метка («Ошибка №1»), под ним раскрываются чипы-детали.

**Зачем.** Зритель видит всю карту ролика и где он сейчас. Детали появляются ровно под словами — конспект пишется сам.

**Когда применять.** Объяснение структуры, чек-листы, «N ошибок».

**Когда не применять.** Если над головой нет места (кадр крупный).

## Как сделать

1. 5 строк по 4% высоты кадра, ширина 50%, над головой; `backdrop-filter: blur(16px)`, белый 18%, скругление 50%, номер в кружке слева.
2. Вход: строки появляются размытыми (blur 10px, текст скрыт) по одной через 3 кадра; на слове-перечислении текст проявляется.
3. Переход к пункту: остальные строки уезжают вверх и исчезают за 8 кадров, выбранная остаётся.
4. Метка над строкой: белая пилюля с красным текстом «Ошибка №1».
5. Под строкой — чипы 2,5% высоты, появляются по словам («срок», «цифра», «трансформация»), затем строка «было → стало».

## Примеры из источников

- `2026-10-30-DejklsxIV31`, 0:05–0:13 — 5 размытых строк → «Хук / Контекст / Напряжение / Поворот / Развязка»; 0:14–0:24 — остаётся «1 Хук», метка «Ошибка №1», чипы и «было → стало».
