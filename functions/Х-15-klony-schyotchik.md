# Х-15 · Клоны ведущего — число пунктов на экране

**Суть.** В хуке «Вот 3 …» в кадре сразу три копии ведущего, плечом к плечу, все показывают один палец. Над головой у каждого — маленькая карточка-превью своего пункта.

**Зачем.** Число из фразы видно глазами, а не только на слух. Три одинаковых человека в кадре — странная картинка, на ней задерживаются. Превью над головами обещают, что дальше будет конкретика.

**Когда применять.** В роликах-списках из 2–4 пунктов, в хуке.

**Когда не применять.** Если пунктов больше 4: клоны не помещаются и превращаются в кашу.

## Как сделать

1. Штатив, камера не двигается. Снять ведущего 3 раза: слева, по центру (ближе к камере), справа. Свет и фон те же.
2. Совместить дубли масками по вертикальным границам. Центральный клон крупнее, так ближе к камере.
3. Первый кадр (0,0–0,8 с) — один ведущий. Дальше склейка на трёх клонов (в источнике на 0:01).
4. Над каждым клоном — карточка-превью 15–20% ширины кадра, со скруглёнными углами. Появляются по очереди с шагом 0,3–0,5 с.
5. Субтитры по одному слову на груди центрального клона.

**В Remotion.** Три `<OffthreadVideo>` с `clipPath` или маски из matte.py, карточки — `<Img>` со `spring()` по `delay`.

## Примеры из источников

- `2026-10-30-De-B80AMBrj`, 0:00–0:05: на 0:00 один ведущий поднимает палец, с 0:01 — три клона с поднятым пальцем и три превью роликов над головами.
- `2026-10-30-Dew7BkiA7QN`, 0:38–0:43 — «двойник»: несколько частей кадра с неподвижной камеры, маской собрана сцена с двумя ведущими.
- `2026-11-04-DfPgFrfst9`, 0:05–0:07 — «хук-клон» первым номером в меню открывашек, пример на 1,4 млн.
