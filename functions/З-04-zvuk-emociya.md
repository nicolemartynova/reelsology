# З-04 · Звук-эмоция на событие и реакцию

**Суть.** На событие или реакцию в кадре накладывается узнаваемый звук, который подсказывает зрителю эмоцию. Он может быть «неправдой»: пластиковая бутылка падает со звуком разбитого стекла. Звук громче речи на короткий момент и длится 0,3–2 с.

**Зачем.** Звук усиливает момент и делает реакцию смешнее или напряжённее. Зритель считывает эмоцию быстрее, чем по лицу.

**Когда применять.** Реакция клиента на цену, неудачный объект на просмотре, момент «озарения» в объяснении.

**Когда не применять.** В серьёзных частях (цифры, юридические условия): мемный звук снижает доверие. Не больше 2–3 звуков на ролик в экспертном тоне.

Полный словарь по задачам, громкость и где брать звуки — в [sounds.md](../sounds.md).

## Словарь звуков (в CapCut: Звуки → Звуковые эффекты → поиск по названию)

| Эмоция | Звук |
|---|---|
| неловкая тишина | сверчки (crickets) |
| провал, не получилось | sorry / failure / mistake |
| взрыв, шок | burn / explosion |
| цензура, крепкое слово | beep (short) |
| удивление | sound effect of the… (удивление) |
| неправильный ответ | wrong answer |
| тревога, мало времени | clock second hand |
| озарение, «чудо» | glitter / sounding |
| удар | damage hitting punch |
| вернуться назад | rewind / fast forward |

## Как сделать

1. Найти в ролике 1–3 момента-события: падение, реакция, озарение.
2. Подобрать звук по словарю, начало звука — ровно на кадр события.
3. Речь под звуком приглушить на 6–10 дБ на время звука.
